# LifeLine 360 – Smart Emergency Response and Hospital Coordination System

## Overview

LifeLine 360 is a full-stack web application designed to support emergency response coordination. It allows users to report emergencies and helps identify available ambulance and hospital resources based on location and emergency severity.

## Key Features

- Emergency registration and tracking
- Ambulance resource management
- Hospital resource management
- Location-based resource search
- Rule-based emergency recommendation
- Map visualization
- Patient registration
- Emergency history and reports

## Technologies

- **Backend:** Java 17, Spring Boot, Spring Data JPA, Hibernate
- **Frontend:** HTML, CSS, JavaScript
- **Database:** MySQL
- **Maps:** Leaflet.js, OpenStreetMap
- **Tools:** Eclipse, Maven, Git, GitHub

## Architecture

Frontend → REST APIs → Spring Boot → JPA/Hibernate → MySQL

## Project Status

Working prototype developed as an academic full-stack project.
